# NEON_BASE — шпаргалки CSS и Git

Учебный проект: две мини-шпаргалки в стиле киберпанка.

- **CSS** — как писать правила, работать с селекторами, цветами, шрифтами и отступами
- **Git** — первые шаги: настройка, создание репозитория, сохранение правок, история

Всё сделано на чистом HTML и CSS, без фреймворков и сборки.

---

## Что внутри

| Страница | О чём |
|----------|-------|
| `index.html` | Титульная страница: глитч-заголовок и переходы к шпаргалкам |
| `css.html` | Шпаргалка CSS — 6 разделов |
| `git.html` | Шпаргалка Git — 7 разделов |
| `style.css` | Общий файл стилей, всё оформление на CSS-переменных |

Внутри каждой страницы примеры продублированы прямо в тексте: команда или свойство
показано кодом и сразу объяснено словами.

---

## Как открыть

Проще всего — двойной клик по `index.html`. Никаких установок не требуется.

Если хочется проверить работу через локальный сервер:

```bash
python -m http.server 8000
```

Затем открой http://localhost:8000

---

## Технологии

- **HTML5** — семантическая разметка
- **CSS3** — CSS-переменные, `clip-path`, `linear-gradient`, `prefers-reduced-motion`
- **Google Fonts** — Orbitron для заголовков, JetBrains Mono для текста и команд

> Шрифты подключаются с Google Fonts. Если интернета нет, сработают запасные
> шрифты, указанные в переменных `--font-head` и `--font-mono`.

---

## Заметки о стилях

- Все цвета собраны в переменных в начале `style.css` — меняешь один раз, меняется вся страница
- Анимации глитча, сетки и полосы сканирования отключаются системной настройкой «уменьшить движение»
- Инлайновых стилей в разметке нет — только классы

## Работа с Git

Типовой цикл для этого проекта:

```bash
git status                        # посмотреть, что изменилось
git add .                         # отметить все файлы
git commit -m "описание правки"   # сохранить
git push                          # отправить на GitHub
```

Служебную папку `.git` в репозиторий не попадает — git её игнорирует автоматически.

---

## GitHub Pages

Чтобы сайт открывался по ссылке без установки:

1. Открой репозиторий → **Settings** → **Pages**
2. В разделе **Build and deployment** выбери ветку `master`, папку `/ (root)`
3. Нажми **Save**

Через минуту сайт будет доступен по адресу
`https://<твой-ник>.github.io/<название-репозитория>/`
