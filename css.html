CSS BASE

Как задаются стили и что они делают. Минимум теории, максимум примеров.

01 / Правило

Любое правило CSS состоит из трёх частей:

селектор {          /* ЧТО стилизуем */
    свойство: значение; /* КАК именно */
}
  • Селектор — адрес элемента: тег p, класс .card или id #main
  • Свойство — что меняем: color, font-size
  • Значение — конкретное значение свойства
Важно: между свойствами ставим ;. Последнее свойство точку с запятой может не требовать, но лучше всегда ставить — так проще дописывать новые строки.

02 / Селекторы

Способов указать элемент три, и у них разный приоритет:

  • p — по тегу. Задаёт стили всем элементам этого типа
  • .class — по классу. Можно повесить на сколько угодно элементов
  • #id — по идентификатору. Должен быть один на страницу, приоритет выше всего

Живой пример

index.html
p // обычный абзац <p class="warn"> // с классом <p id="lead"> // с идентификатором

В style.css это выглядит так:

p        { color: #333; }         /* 1 — приоритет 1 */
.warning { color: #ffc247; }     /* 10       */
#lead    { color: #00f0ff; }     /* 100      */
Запомни: тег 1 < класс 10 < id 100. Если элемент подпадает под несколько правил — победит то, у которого «вес» больше.

03 / Цвет и фон

Цвет текста — свойство color. Цвет подложки — background-color.

p { color: crimson; }                        /* название цвета */
.box { background-color: #0b0f1a; }           /* HEX: # + 2 цифры красный,
                                                 2 зелёный, 2 синий */
.gradient { background: linear-gradient(90deg, #00f0ff, #ff2d95); }
  • rgb(r, g, b) — числа от 0 до 255. Классика
  • rgba(r, g, b, 0.5) — тот же цвет, но полупрозрачный
  • linear-gradient(угол, цвет1, цвет2) — плавный переход между цветами
Подсказка: цвет удобно выбирать в DevTools браузера (F12) — кликни на элемент, в разделе Styles увидишь его текущий цвет и сможешь поменять на глаз.

04 / Шрифты и текст

body {
    font-family: "JetBrains Mono", Consolas, monospace;
    font-size: 16px;
    line-height: 1.6;
}

h1 { font-weight: bold; }     /* или 700 */
em { font-style: italic; }

p.center { text-align: center; }
p.indent { text-indent: 2em; }
  • font-family — шрифт. Второй вариант через запятую нужен на случай, если первого нет в системе
  • font-size — размер. Можно в px, em (относительно родителя) или rem (от корня страницы)
  • font-weight — толщина: normal / bold / числа 100–900
  • line-height — межстрочный интервал. Удобно в множителях: 1.6 = в полтора раза больше шрифта
  • text-align — выравнивание: left / center / right / justify
  • text-transform — регистр: uppercase (капс), lowercase, capitalize
  • text-decoration — подчёркивание underline или зачёркивание line-through

Шрифты подключаются двумя способами:

  • Ссылкой на Google Fonts в <head> — нужен интернет
  • Файлом @font-face — шрифт лежит рядом с сайтом, интернет не нужен

05 / Размеры и отступы

Вокруг каждого элемента есть четыре отступа. Запомни их по часовой стрелке, начиная с верха:

margin: 10px 20px 30px 40px;
/*      ↑     ↑     ↑     ↑
       сверху справа снизу  слева   */
  • margin — отступ снаружи элемента, от соседей
  • padding — отступ внутри элемента, от его рамки до содержимого
  • border — рамка. Пишется как 1px solid #00f0ff: толщина, стиль, цвет
  • width / height — размер содержимого

Можно задавать все четыре стороны сразу — сокращения:

padding: 10px;             /* со всех сторон */
padding: 10px 20px;       /* сверху/снизу, слева/справа */
padding: 10px 20px 30px; /* сверху, слева/справа, снизу */
margin: 0 auto;          /* 0 сверху/снизу, auto слева/справа = центрирование */
box-sizing: border-box — очень полезное свойство (уже стоит в нашем style.css). Оно заставляет width считаться вместе с padding и border. Без него блок с width: 300px и padding: 20px будет шириной 340px, и это почти всегда неожиданность.

06 / Итого

  • Правило: селектор { свойство: значение; }
  • Приоритет: тег < класс < id
  • Цвет текста — color, фон — background-color
  • font-family, font-size, line-height отвечают за текст
  • margin снаружи, padding внутри, border между ними
  • 0 auto центрирует блок
